Yar AI — ONLY CHANGES
=======================

این ZIP کل پروژه نیست.
فقط فایل‌هایی را شامل می‌شود که برای تغییرات رابط چت/آپلود لازم‌اند:

1) index.html
   - بارگذاری نسخه جدید yar-chat-upgrade.js با cache-busting

2) yar-chat-upgrade.js
   - دکمه + کنار چت
   - منوی یکپارچه فایل/عکس/ویدیو/ZIP
   - تاریخچه و چت جدید و حذف چت
   - ذخیره conversationها
   - پشتیبانی انتخاب فایل عمومی (*/*) علاوه بر فرمت‌های تخصصی
   - تحلیل PDF/DOCX/XLSX، عکس، ویدیو و ZIP

نحوه استفاده:
فایل‌های همین ZIP را روی فایل‌های هم‌نام پروژه فعلی جایگزین کنید.
این ZIP به‌تنهایی یک پروژه قابل اجرا نیست.
